基于岭回归算法的运动者立定姿态研究
摘要
随着大中小学生对自身体质健康的关注和发展，在体育场周边安装摄像头捕捉学
生的体育动作，分析学生运动姿态，实现AI 辅助智能体测，益于运动者进行姿态纠正
和成绩提升。本文主要通过建立岭回归预测模型，分析影响跳远成绩的关键因素，预
测运动者可能达到的理想成绩。
针对问题一: 首先对附件1 中运动者脚部的4 个关键点（29_Y、30_Y、31_Y、32_Y）
数据进行预处理，利用邻近点均值填充修正异常值，利用Savitzky-Golay 滤波器进行数
据平滑处理，同时对数据进行一阶差分。然后利用差值大于设定阈值确定起跳时刻，接
着利用左脚脚尖脚跟、右脚脚尖脚跟差值小于给定阈值，且四点均值靠近参考水平线（起
跳前均值线）确定落地时刻，还需要同时满足Y 轴变化的最大值在该区间范围内，得到
运动者1 的起落帧为123、138，运动者2 的起落帧为165、178。最后利用重心位移及
速度、关键帧姿态和滞空时长描述运动者的滞空阶段。
针对问题二: 该问题主要是探讨影响运动者跳远成绩的因素。首先利用腕、肩、髋、
膝、踝、脚尖数据计算起跳阶段发力帧和起跳帧的肩角、髋角、膝角、踝角、躯干前倾
角的姿态数据；然后利用皮尔逊相关系数对个人体质进行特征提取，得到姿态和体质的
特征数据集；接着对特征数据集进行归一化处理，以消除不同特征在数量级上的差异；
最后基于建立的岭回归预测模型，分析特征数据集中姿态、体质对跳远成绩的影响。将

一 、问题综述
1.1 问题提出
问题1: 根据附件1 中的立定跳远视频、位置信息和跳远成绩和附件2 整个跳远过
程中的33 个关键节点在视频不同帧位置坐标，得出运动者在跳远过程中的起跳和
落地时刻，并且描述滞空阶段的运动过程。
问题2: 根据附件3 一些立定跳远者在纠正前、教练纠正姿势后的跳远视频、位置
信息和和跳远成绩，再根据附件4 运动者的个人体质报告，包括年龄、身高、体重
和体脂率等，分析影响运动者跳远成绩的主要因素。
问题3:根据问题1 和问题2 的模型和结果，再结合附件5 中运动者11 的跳远视频

问题4:在问题3 的基础上，给出短时间内提升运动者11 的跳远成绩的姿势训练建
议，以及经过短期训练后该运动员可能达到的理想跳远成绩。
1.2 问题背景
随着大中小学生自身体质健康的发展,用于学生体育运动姿态捕捉技术面临着诸多
挑战, 如: 人工手动捕捉效率以及准确度太低, 对人员技术以及经验有一定要求等, 有
关资料显示：传统人体姿态捕捉技术存在不能准确地表示出学生动作的优点和缺点，无
法给出身体变化的细节数据等，而在学生对自身运动姿态的关注需求不断扩大, ,传统的
捕捉方式容易产生数据无法显现, 捕捉的动作不清晰等问题, 严重影响了教师对学生不
正确的运动姿态要做出的方案. 因此我们需要寻找新的方式给出合理的运动动作方案.
而今，AI 人体姿态估计技术的出现不仅可以帮每个学生找到自身动作的优缺点而
且还解决了更多的问题，比如：在学生进行跳远的运动中可以捕捉并分析每个学生的起
跳瞬间的腿部发力动作，手臂摆动轨迹，身体腾空的姿态等等一系列所身体变化的数据。
AI 人体姿态估计技术的准确，清晰的特点，不仅可以让自己对于自己的动作有准确的判
断对教师而言可以更快，更好的对每个学生的动作做出良好的方案。对AI 智能辅助体
测的发展有了卓越的进步。

四 、问题分析
4.1 问题分析
本次是以AI 人体姿态估计技术为背景, 需要解决运动者在跳远过程中的起跳和落
地时刻，并根据给出的资料来分析影响运动者体跳远成绩的主要因素，再根据附件5 中
的跳远视频和附件4 的个人体质信息预测运动者的实际跳远成绩，最后根据上一个问题
的分析结论，给出姿势训练建议和短期训练后该运动者可能达到的了理想跳远成绩。
4.1.1 问题一：
本问要求根据附件1 的两位立定跳远运动者的跳远视频、位置信息和跳远成绩确认
运动者在跳远过程中的起跳和落地时刻，其中位置信息包含运动者在整个跳远过程中的
33 个关键节点在视频不同帧的位置坐标。首先，结合起跳和落地的假设，即只考虑脚跟
及脚尖位置，故只选取33 个关键节点里面的4 个点信息（左脚跟29、脚尖31、右脚跟
30、脚尖32），然后对数据进行预处理，最后通过差值来判断起跳时刻，并根据脚跟和
脚尖是否水平（同时落地）来判断落地时刻。
4.1.2 问题二：
本问要求根据附件3 中立定跳远运动者们在教练纠正姿势前后的跳远视频、位置信
息和跳远成绩和附件4 运动者们的个人体质报告（包括体脂率、肌肉重量、内在脂肪和
标准体重等信息）来分析影响运动者立定跳远的主要因素。首先基于文献查阅法找出影
响运动者跳远成绩的可能因素，并观察运动员在起跳过程中对运动员跳远成绩影响比较
大的几个因素，如在个人跳远动作姿态中肩关节、髋关节、膝关节和躯干前倾的角度，
然后基于相关性分析提取个人体质报告中相关性较大的特征（骨骼肌重量、体脂率和肌
肉率等信息），最后根据跳远阶段的关节角度和提取的个人体质特征，利用回归分析方
法剖析影响运动者立定跳远成绩的重要因素。

六 、模型评价
6.1 模型的优点
本文使用的岭回归算法具有可对变量之间共线性比较严重或病态数据偏多的
数据类型作回归分析，对这类数据作回归得到结果更符合实际、更可靠等优点。
岭回归模型可以防止过拟合，提高模型泛化能力，通过正则化惩罚。岭回归倾
向于产生更小、更分散的系统，避免了模型过于复杂的拟合训练数据中的噪音。
岭回归模型是用引入一点偏差的代价，换来了方差的大幅度降低，从而在整体
上获得了更优的预测精度。
6.2 模型的不足
岭回归模型会导致欠拟合，虽然回归通过引入正则化项减少了模型的复杂度，
防止了过拟合，但这也可能导致模型在训练集上的拟合能力下降，从而出现欠
拟合的情况。
岭回归模型的选择较为复杂，岭回归需要选择一个合适的岭参数，不同的岭参
数会对模型的性能产生显著影响。
